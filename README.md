# 夏休み妖怪日記

田舎の祖母の家で過ごす約30日間の夏休みを描く、Godot製の3Dアドベンチャーゲームです。妖怪を倒したり図鑑を埋めたりすることではなく、プレイヤー自身の体験を「自分だけの夏休み妖怪日記」として残すことを目指します。

現在は、河童との出会いを含む「1日版 Vertical Slice」のための基盤を開発しています。

現在のグレーボックスでは、祖母の家を出て田舎道と田んぼの間を進み、川と橋まで歩けます。Debug MenuのArea表示は `grandma_house` → `village_road` → `river` と切り替わります。

祖母に近づいて `E` を押すと朝の会話が始まります。会話は `E` または `Space` で進められ、会話中はPlayerとゲーム内時計が停止します。

GameClockは太陽、環境光、空色へ接続されています。F3のDebug Menuから時刻を変更すると、朝・昼・夕方・夜の照明を即座に確認できます。

祖母の家から川までの道沿いには虫が3匹います。`BUG`表示へ近づき、プロンプトが出た状態で `E` を押すと捕獲でき、種類別の捕獲数が画面右上に表示されます。

05:00〜19:00に川へ近づくと、河童らしき影が一度だけ短時間現れます。発生済みイベントはEventManagerへ記録され、同じプレイ中には再発しません。

河童を目撃すると夕方へ進み、帰宅目標が表示されます。祖母の家に戻って `RETURN HOME` 地点を調べると、その日の虫・イベント・帰宅時刻をDayRecordへ確定し、1日のサマリーを表示します。

サマリーの後は妖怪日記が開きます。1〜3キーで残したい記憶を選び、`E`または`Space`で日記を確定すると1日版Vertical Sliceが完了します。

日記確定時には `user://save_01.json` へオートセーブします。デバッグ実行ではF3メニューのSave / Loadから同じスロットを手動操作できます。フォーマットは [SAVE_FORMAT.md](docs/SAVE_FORMAT.md) を参照してください。

## 必要環境

- Godot 4.7.1 stable
- Git
- 3Dアセットを編集する場合は Blender

## 起動方法

1. Godot Project Managerで、このディレクトリの `project.godot` をImportします。
2. エディタ右上の「プロジェクトを実行」または `F6` / `F5` で起動します。
3. デバッグ実行中に `F3` を押すとDebug Menuを開閉できます。

### 現在の操作

- `W` / `A` / `S` / `D`：移動
- マウス：カメラ操作
- `Space`：ジャンプ
- `E`：近くの対象を調べる・話す
- `Escape`：マウスカーソルを解放
- 左クリック：マウスを再キャプチャ
- `F3`：Debug Menu

コマンドラインでは、Godot実行ファイルにパスが通っている場合、次でも起動できます。

```powershell
godot --path .
```

## 開発方針

- まず「河童と出会う1日」を15〜20分で遊べるVertical Sliceとして完成させます。
- 巨大なGameManagerは作らず、状態と機能を小さなサービスへ分離します。
- イベントや妖怪などのコンテンツは、可能な限りResourceによるデータ駆動にします。
- 本編30日分や大量のコンテンツは、Vertical Sliceの面白さを検証してから拡張します。

詳細は [開発計画](docs/DEVELOPMENT_PLAN.md)、[ゲームデザイン](docs/GAME_DESIGN.md)、[アーキテクチャ](docs/ARCHITECTURE.md) を参照してください。
