# アセット要件

## 目的

本書は「河童と出会う1日」Vertical Sliceで必要になる画像、3Dモデル、アニメーション、音声、フォント、VFXを明文化する。素材を探す・制作する・生成する前に、用途と導入先を確認するための発注表兼チェックリストとして使う。

現在の `assets/` 配下には `.gitkeep` 以外の実素材はない。既存画面の箱、円柱、単色UI、無音のAmbientProfileはすべて仮素材である。

## 優先度

| 優先度 | 意味 |

| P0 | Vertical Sliceの魅力を判断するために必須 |
| P1 | P0完成後に品質を引き上げる |
| P2 | 本編拡張時に制作する。現時点では作らない |

## 仮のアート方針

- 少し懐かしい日本の田舎の夏。年代を断定しすぎず、昭和末期〜平成初期を思わせる生活感を持たせる。
- 写実一辺倒ではなく、形を読み取りやすい軽いスタイライズ表現にする。
- 昼の生命感、川辺の涼しさ、夕方の寂しさを色・音・密度で区別する。
- 河童は最初から全身を見せず、色、波紋、音、短いシルエットで想像させる。
- ホラーではなく「少し怖いが、もっと知りたい」を狙う。

詳細な画面方針は [VISUAL_DIRECTION.md](VISUAL_DIRECTION.md) を参照する。

### 環境モデル仕様

- 形式：`.glb` を基本とする。
- 単位：Godot上の1ユニットを1mとする。
- 原点：設置物は接地面中央、扉や回転物はヒンジ位置に置く。
- マテリアル：1モデルあたり原則1〜4個。共通素材は再利用する。
- テクスチャ：主要物は2048px以下、小物は1024px以下を基本とする。
- LOD：Vertical Sliceでは必須にしないが、木や草はMultiMesh化できる構造にする。
- コリジョン：見た目用メッシュと単純な衝突形状を分離する。
- 細い電線や草に物理コリジョンを付けない。

- 写真調素材と手描き素材を無計画に混在させない。

- 生成AIを使用した場合は、利用モデル、生成日、プロンプト概要、編集内容をライセンス台帳へ残す。

### 環境音仕様

- 形式：ループ音はOgg Vorbis、44.1kHzまたは48kHz、ステレオ。
- ループ境界にクリック、急な音量差、目立つ同一イベントの反復がないこと。

- 現在の接続先は `resources/audio/*_ambience.tres` の時間帯別AudioStream欄。

## ライセンスと出典管理

素材を追加するときは `assets/ATTRIBUTION.md` に以下を記録する。

- アセットIDとファイルパス。
- 作者・配布元・取得URL。
- ライセンス名と取得日。
- 改変の有無と内容。
- クレジット表記の要否。
- 生成AI利用の有無。

出典や利用条件が不明な素材はリポジトリへ追加しない。検索結果の画像や動画から音声・画像を無断転用しない。

## 導入時チェックリスト

- [ ] P0用途のどれを置き換える素材か明確である。
- [ ] ライセンスと出典を記録した。

- [ ] Grayboxの衝突判定やイベント位置を壊していない。
- [ ] `assets/ATTRIBUTION.md` を更新した。
