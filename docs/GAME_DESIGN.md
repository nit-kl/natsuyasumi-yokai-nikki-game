# ゲームデザイン

## ビジョン

『夏休み妖怪日記』は、田舎の祖母の家で過ごす約30日間の夏休みを、自分の思い出として持ち帰る3Dアドベンチャーゲームである。

> あの夏、ぼくにだけ、妖怪が見えた。

妖怪の討伐、レベル上げ、図鑑のコンプリートを目的にはしない。虫取り、釣り、川遊び、町の探索、人や妖怪との交流など、プレイヤーが選んだ過ごし方そのものを日記として残す。

## デザイン原則

1. 妖怪は敵ではなく、観察し、遊び、助け合い、関係を築く相手にする。
2. クエストマーカーや報酬リストではなく、噂、音、景色、会話などの「気になること」で探索を促す。
3. すべてのイベントを見ることを前提にしない。見逃しも含めて、その人だけの夏にする。
4. 座る、海を見る、昼寝をするなど、何もしない時間にも意味を持たせる。
5. 妖怪は突然出現させず、最初からそこにいた存在へプレイヤーが気付くように演出する。
6. 効率や達成率ではなく、「この町で夏休みを過ごした」という感覚を最終成果にする。

## 1日の基本ループ

```text
起床・朝食・家族との会話
  → 天気や町の様子を知る
  → 自由行動（探索・遊び・交流）
  → 昼から夕方へ
  → 帰宅、または夜の探索
  → 夕食・風呂・家族との会話
  → 妖怪日記
  → 就寝
```

ゲーム内の1日は20〜35分を目安とし、プレイテストで調整する。

## 時間帯と雰囲気

| 時間帯 | 基準時刻 | 体験の軸 |
| --- | ---: | --- |
| 朝 | 05:00 | 鳥、食卓、ラジオ。今日への期待 |
| 昼 | 10:00 | 蝉、川、強い日差し。自由な探索 |
| 夕方 | 16:30 | 長い影、ヒグラシ。帰り道への意識 |
| 夜 | 19:00 | 風鈴、蛙、月明かり。静かな不思議 |

## Vertical Slice：「河童と出会う1日」

最初の開発目標は、15〜20分程度で完結する1日版である。

- 朝：祖母の家で起床し、祖母と短く話して外へ出る。
- 昼：田舎道を自由に歩き、途中で虫を捕る。
- 川：河童の気配を段階的に感じ、最後に一瞬だけ目撃する。
- 夕方：空、光、環境音が変わり、帰宅したくなる空気を作る。
- 夜：祖母の家で夕食をとり、その日の出来事を日記にする。
- 終了：1日の記録を表示する。

### 成功条件

- 田舎を歩くだけでも少し楽しい。
- 川へ行きたくなる。
- 虫取りが最低限気持ちいい。
- 河童を見つけた時にワクワクする。
- 夕方になると自然に帰りたくなる。
- 日記によって1日の体験に意味が生まれる。

6項目をプレイテストで確認できるまでは、本編30日分の制作へ進まない。

## Vertical Sliceの対象外

30日分のイベント、妖怪25体、釣り、秘密基地、自転車、海、山、夏祭り、大量のNPC・UI、高度な写真システム、実績、Steam連携は後続フェーズへ回す。

より詳細なコンテンツ、システム、マイルストーンは [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) を正とする。
