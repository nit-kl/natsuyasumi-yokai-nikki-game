# 移動マーカー先行の背景制作フロー

## 目的

背景の見た目から侵入不可領域を推測して移動を後付けするのではなく、先に「この画面でどこを散歩できるか」を決め、その契約に合わせて背景を制作する。
移動の正本は各Sceneの`WalkPathNetwork2D`であり、背景画像や別のMarker座標表ではない。

## 必須の制作順

1. 640x360のGreyboxで出入口、Spawn、NPC生活地点、虫、必須Event地点を置く。
2. `WalkPathNetwork2D`の`Line2D`で主経路、寄り道、分岐を定義する。
3. 常時表示Markerを有効にし、全目的地点がInteraction距離内に入ることを確認する。
4. Marker付きGreyboxを背景制作用レイアウトとして固定する。
5. Marker列を中心に、室内は36px以上、屋外は40px以上を目安とした連続歩行面を背景へ描く。
6. 家具、水面、水田、畑、岩、柵、植栽などを歩行面の外へ配置する。
7. 生成原寸を`map_<area>_source.png`、Nearestで640x360へ縮小した画像を`map_<area>.png`として保存する。Markerは背景へ焼き込まない。
8. Sceneへ背景を接続し、Collision、Foreground Occluder、出入口、Event位置を背景の足元へ合わせる。
9. `walk_path_marker_smoke_test`と全Validationを実行し、Marker付き実画面を目視確認する。

基準画像は次のコマンドで更新する。

```powershell
powershell -ExecutionPolicy Bypass -File tools/capture_marker_first_baselines.ps1 -GodotPath <Godot console executable>
```

Linux / Cursor Cloudでは描画可能なDisplayを指定して実行する。

```bash
DISPLAY=:1 tools/capture_marker_first_baselines.sh
```

出力先は`docs/art-reference/03_gameplay/marker_first_geometry/`で、各Locationについて`*_markers.png`と`*_geometry.png`を保存する。

背景生成・編集を先に行い、その絵の隙間へ後から経路を押し込む手順は禁止する。

## 背景制作用プロンプト契約

画像生成または外注指示には、最低限次を含める。

- Image 1を既存背景またはGreyboxの編集対象として明記する
- 最終640x360座標で全経路点を列挙する
- 経路を中心とした必要歩行幅を指定する
- 維持する出入口、視点、画面比率、Pixel密度を指定する
- 経路から退避するオブジェクト種別を指定する
- 人物、UI、矢印、Marker、文字を背景へ描かないよう指定する

## 完了条件

- 全Markerが床、畳、土道、橋、乾いた川岸のいずれかに見える
- Markerの2px範囲がWorld Collisionと重ならない
- Marker間に家具、水、作物、岩、柵、密な植栽が割り込まない
- 出入口、NPC、虫、必須Eventへ経路上から到達できる
- Markerを非表示にしても歩行面が自然な背景として成立する
- Markerがクエスト目的地や妖怪の気配に見えない
- Marker付き画像とGeometry Overlay画像がVisual Regression基準として保存されている
