# ビジュアル全面刷新計画

## 決定

ゲーム内容と進行システムは『夏休み妖怪日記』独自のまま維持し、画面構成、背景、建造物、キャラクター、UIを全面的に刷新する。既存3D素材は完成品ではなく、動作確認用プロトタイプとして扱う。

## 新しい画面の基準

- 固定寄りの斜め見下ろしカメラを使い、1画面を小さな情景として構成する。
- 現実の縮尺や移動距離より、前景・中景・背景の重なりとランドマークの読みやすさを優先する。
- 道、家、水路、田畑を画面内で斜めに交差させ、水平・垂直だけの配置を避ける。
- 主人公は低頭身かつ大きめの頭・手足で、遠景でも行動と向きが読める形にする。
- 建物は屋根、軒、玄関、窓、生活小物のシルエットを誇張し、細部より輪郭を優先する。
- 素材は手描き感のある色むらと経年変化を持たせ、写実的な高解像度素材の寄せ集めにしない。
- 昼の安心と夕方以降の不穏さは、同じ構図の色・影・音の変化によって表現する。

## 維持するもの

- `GameState`、`GameClock`、セーブ、日記、会話、イベント、音声管理。
- 「祖母宅から川へ行き、河童を見て、帰宅して日記を書く」というVertical Slice。
- 既存シーン内の当たり判定、イベント条件、データResource。ただし見た目に合わせた位置調整は行う。

## 作り直すもの

- プレイヤーカメラと画面基準の移動感。
- 祖母宅、道、田んぼ、川、橋、電柱、植生の比率と配置。
- 主人公、祖母、河童、虫の造形と配色。
- タイトル、会話、目的表示、虫捕り、日記のUI。
- 地面、屋根、木、葉、水面など主要マテリアル。

## 実装段階

1. `diorama_composition_study.tscn` でカメラ、密度、キャラクターの画面占有率を決める。
2. 祖母宅と庭を新基準で作り直す。（祖母宅外観・庭の生活クラスター・主人公・祖母の初期刷新まで完了）
3. 田んぼ道と川辺を、個別の情景が連続する構成へ再配置する。（田んぼ道の緩いS字、4枚の水田、畦道、分節した用水路、川の蛇行、河童側の浅瀬と観察地点まで反映済み）
4. 主人公と祖母を低頭身デザインへ作り直す。（約3頭身の主人公と約3.2頭身の祖母へ刷新済み）
5. UIと主要マテリアルを新しい色・形へ統一する。（タイトル、目的表示、会話、通知、虫捕り、日記を生成り・墨・藍・朱の共通Themeへ統一済み）
6. 本編シーンへ置換し、イベント位置とセーブ互換を確認する。（開発用常時表示を撤去し、進行座標を維持、旧セーブ座標の安全検証まで反映済み）

実画面確認で判明した祖母宅の外観・室内同時表示、屋根内の初期配置、画面を横切る仮電線と側溝ディテールは修正済み。室内、電線、道路ディテールは、専用の見せ方または造形へ更新するまで本編では非表示とする。

固定箱庭カメラは近景の切れと巨大化を抑えるため、正投影サイズを `9.5` から `12.5` へ変更し、家・道・川の周辺情報が同時に読める基準へ更新した。

## 判定基準

- 1280×720の静止画だけで、日本の田舎の生活圏と主人公の次の進行方向が分かる。
- 主人公、家、道、水辺の優先順位が明確で、背景の情報量に埋もれない。
- 同一地点の昼と夕方で、安心と不穏の印象が明確に変わる。
- 画面外を想像させる前景遮蔽があるが、移動や操作を妨げない。
- 既存作品の固有UI、キャラクター、建物配置を複製せず、本作の妖怪観察と日記に結び付いている。
